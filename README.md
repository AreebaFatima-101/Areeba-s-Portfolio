# Areeba Fatima — Portfolio

Personal portfolio website showcasing my projects, skills, and experience
in AI/ML, software development, and software quality assurance.

🔗 **Live site:** [add your Netlify URL here]

## Tech Stack

- **Frontend:** React (Vite)
- **Backend:** Node.js + Express (handles the contact form)
- **Styling:** Custom CSS, no framework

## Features

- Responsive dark-themed design
- Animated starfield background with a scroll-driven planet graphic
- Orbiting skills visualization with real tool logos
- Sections for About, Skills, Experience, Projects, Certifications, and Contact
- Working contact form that sends email via the Node backend
- Downloadable resume

**Deployed**
**Frontend**
\`\`\`bash
cd client
npm install
npm run dev
\`\`\`

**Backend** (needed for the contact form to send email)
\`\`\`bash
cd server
npm install
npm start
\`\`\`
